# 星海の浜辺

VRChatワールド「Ploom RooM — 星海の窓辺」で育てた水槽を、Androidで確認できます。コイン、XP、魚のレベル、探索隊の帰還予定を表示します。

| お使いの端末 | ダウンロード |
| --- | --- |
| Android 8.0 以降 | [星海の浜辺 v1.1.0 APK](https://raw.githubusercontent.com/L1ZeroX/star-sea-aquarium-vpm/main/seaside/StarSea-Seaside.apk) |
| Windows PC | [PC同期ツール・APK・使い方 v1.1.0 ZIP](https://raw.githubusercontent.com/L1ZeroX/star-sea-aquarium-vpm/main/seaside/StarSea-PC-Android.zip) |

## 初めて使うとき

1. PCでZIPを展開し、`StarSea-Sync.exe` を開きます。スマホでは上のAndroid用APK、またはPCツールに表示されるQRからアプリをインストールします。
2. スマホとPCを同じ自宅ネットワークにつなぎます。スマホアプリの「読み込む → PCと接続」で、PCツールに表示されるIPアドレスを入力します。
3. 両方の端末の8桁の番号を照合して、PCで接続を許可します。
4. 水槽の「引き継ぎ → コード発行」でコードを全文コピーします。PCツールが起動していれば、アプリを開いたときに最新のコピーが反映されます。

スマホだけで使う場合は、アプリの「読み込む」にコードを貼り付けてください。水槽の数値はコード発行時点の記録です。外出中も最後に取り込んだ記録を開けます。
